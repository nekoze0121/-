## 本文

### はじめに

「副業、始めたいけど時間がない」
そう思ったまま、もう半年以上経っていませんか。

こんにちは。この記事では、**通勤電車やバスの中、たった15分だけ**を使って取り組める、AIライティングの副業のやり方をお伝えします。特別なスキルも、パソコンも、まとまった自由時間も必要ありません。スマホひとつで、今日から始められます。

### こんなお悩み、ありませんか？

- 副業に興味はあるけど、平日は仕事で疲れていて、休日も家族との時間や自分の休養で手一杯
- 会社に本業以外の収入があるとバレたくない。同僚にも家族にも、絶対に知られたくない
- ライティングの副業に興味はあるけど、文章を書くのが得意じゃない。AIを使えばいいと聞くけど、ツールの月額課金がどんどん積み重なって、結局稼げないまま赤字になりそうで怖い
- SNSを見ると「副業で月10万円達成しました」という投稿がたくさん流れてくる。自分だけ置いていかれている気がする

一つでも当てはまるなら、この記事はあなたのために書きました。

### でも、このままでいいんでしょうか

会社の給料だけに頼る生活は、正直なところ心もとないと感じている方は多いと思います。かといって、いきなり大きな副業に手を出す勇気もお金の余裕もない。高額な副業スクールに申し込んで、逆に損をするのが一番怖い。

そう感じているなら、まずは「小さく、リスクなく、隙間時間だけで」試せる方法から始めるのが一番の近道です。

### 「通勤時間の15分」で完結するAIライティングという選択肢

この記事でお伝えするのは、AIを使ったライティングの副業です。ポイントは2つあります。

1. **文章の骨組みはAIが作ってくれる**ので、ゼロから自分で考える必要がありません。あなたがやるのは、AIが出した文章を確認して、必要な部分だけ整えることです。
2. **スマホひとつ、通勤時間の15分だけで完結する作業フロー**に絞っています。パソコンを開く必要も、まとまった時間を確保する必要もありません。

いわゆる「コピペ」に近い感覚で、AIが下書きした文章を軽く整えて納品する。これが今回のやり方の基本の流れです。もちろん、まったく何もせずに放置していてお金が入ってくるわけではありません。ですが、ゼロから文章力を磨く必要がないぶん、始めるハードルはかなり低くなっています。

なぜスマホと15分だけで完結するのか、なぜ身バレのリスクを抑えられるのか——その仕組みと具体的な手順は、この続きで詳しくお伝えします。

### 実際の手順：スマホだけで完結する3ステップ

ここからは、実際にあなたが通勤時間にやることを、順番に説明します。

**ステップ1: AIチャットアプリに「お題」を投げる**
スマホのAIチャットアプリ（ChatGPTなど）を開き、この記事の後半で渡すプロンプトテンプレートに沿って、ライティング案件のお題を入力します。ここは1〜2分で終わります。

**ステップ2: 出てきた文章にサッと目を通す**
AIが出してくれた文章を読み、明らかにおかしい部分（事実と違う、日本語が不自然、指示と違う）がないかだけ確認します。じっくり推敲する必要はありません。あくまで「チェック」です。

**ステップ3: 気になった部分だけ直して納品する**
気になった箇所があれば、その部分だけ自分の言葉で軽く直します。全体を書き直す必要はありません。クラウドソーシングサイトの納品フォームに貼り付けて完了です。

この3ステップを、通勤中の15分で回します。最初は不慣れで時間がかかるかもしれませんが、慣れてくると作業時間はぐっと短くなります（個人差があります）。

**身バレを避けるための注意点**
- クラウドソーシングサイトのプロフィールには本名・勤務先が分かる情報を載せない
- 案件のやり取りは個人のSNSアカウントと紐づけない、専用のメールアドレスを用意する
- 執筆ジャンルは自分の本業と関連の薄い分野を選ぶ（同業者に見つかるリスクを避ける）

### すぐ使えるプロンプトテンプレート集

以下は、実際にAIチャットアプリに入力するプロンプトの型です。角括弧の部分を案件内容に合わせて書き換えるだけで使えます。

```
あなたは日本語のWebライターです。以下の条件で記事を作成してください。

テーマ: [案件で指定されたテーマ]
文字数: [指定文字数]
読者対象: [想定読者]
トーン: [丁寧/親しみやすい/専門的 など]

制約:
- 誇張表現や断定的すぎる表現は避ける
- 一文はできるだけ短く、読みやすくする
- 見出しを使って構成を整理する
```

このほか、案件の種類別に使えるテンプレートを2つ、下の【特典】セクションでお渡しします。

### 【特典】案件別プロンプトテンプレート集

**見出し構成だけを先に作らせるプロンプト**（長めの記事で、いきなり本文を書かせると散らかる場合に）

```
あなたは日本語のWebライターです。以下のテーマで、まず見出し構成（h2/h3）だけを箇条書きで提案してください。本文はまだ書かないでください。

テーマ: [案件で指定されたテーマ]
想定文字数: [指定文字数]
読者対象: [想定読者]
```

構成案が出たら、その中から良さそうな流れを選んでから本文生成に進むと、書き直しの手間が減ります。

**表現を柔らかく言い換えさせるプロンプト**（AIの下書きが硬い・断定的すぎると感じたときに）

```
以下の文章を、断定的すぎる言い回しを避けて、少し柔らかいトーンに言い換えてください。意味は変えないでください。

[AIが出した文章を貼り付け]
```

この2つを、最初にお伝えした基本のプロンプト（お題を投げるためのテンプレート）と組み合わせて使うと、修正の往復が少なくなります。
