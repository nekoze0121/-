# 健康診断では「異常なし」。でも、なんとなく体が重い人へ

## 本文

健康診断では「異常なし」。でも、なんとなく体が重い。

そんな状態が続いていないだろうか。はっきりした痛みや症状があるわけではないのに、朝からだるい、集中力が続かない、疲れが抜けない。病院に行くほどでもない気がして、そのまま様子を見ているうちに、その状態が「いつもの自分」になってしまっている。

正直に言うと、こうした「なんとなく不調」は、検査の数値には出にくいだけで、日々の生活習慣の積み重ねからきていることが多いと思う。一つひとつは小さな習慣でも、積み重なると体の余力を削っていく。

これからお伝えするのは、症状を診断する方法ではない。あなた自身の生活習慣を振り返り、負担が積み重なっていそうな部分に気づくためのチェックリストだ。体調について気になることがあれば、この記事の内容にかかわらず、医療機関に相談することを前提にしてほしい。

なぜ、検査には出ない不調が起こるのか。いくつかの背景が考えられる。

一つ目は、生活習慣による負担は、単発の検査では見えにくいことだ。血液検査や健康診断は、その時点での数値を見るものであり、日々の睡眠不足や姿勢の悪さの積み重ねまでは反映されにくい。

二つ目は、不調に慣れてしまうことだ。少しずつ体調が下がっていくと、その状態が「普通」になり、自分では気づきにくくなる。以前と比べて何が変わったのか、振り返る機会がないと見えてこない。

三つ目は、我慢することに慣れすぎていることだ。多少のだるさや疲れを、仕事や日常の中で後回しにし続けているうちに、それが当たり前になってしまう。

こうした背景がある以上、「特に異常はない」という検査結果だけで安心して終わりにするのではなく、自分の生活習慣を一度棚卸ししてみることが役に立つ。

生活習慣を睡眠・食事・水分・身体の使い方の3つの視点で振り返るチェックリスト、気づいたことの記録の付け方、医療機関に相談する目安の考え方は、以下の有料noteでまとめてお伝えしている。
