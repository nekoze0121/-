# 商品情報フォルダ（共通資料）

商品企画部が確定したコンセプトを、商品ごとに1ファイルとして保存する場所。単一ファイルの上書きにしない理由は、CLAUDE.mdの「ニッチ方針（ポートフォリオ制）」により複数商品が同時並行で進行するため（`note/企画/進行キュー.md`参照）。

## ファイル命名規則

`YYYY-MM-DD_テーマ名.md`（確定した日付＋テーマ名）。既存の`note/企画/`本文ファイルの命名規則と揃えている。

## 記載する内容（商品企画部が確定時に作成）

- タイトル案・ターゲット・USP
- 想定価格帯（既定は¥500固定。逸脱する場合は根拠）
- 簡易目次構成
- tester/criticでの採用理由
- 対応する`note/企画/進行キュー.md`の行へのリンク

有料note部・無料note部・X集客部は、このフォルダ内の該当ファイルを「その商品の確定情報」として参照する。ファイルが存在しない（＝商品企画部の確定作業が終わっていない）テーマには着手しない。

## 既存3商品について

2026-08-22に企画・執筆済みの3商品（通勤AIライティング／AI×LINEスタンプ内職／AIナレーター副業）は、4部署体制の導入前に作られたため、このフォルダには商品情報ファイルを作成していない（体制構築のみが今回のスコープのため）。これら3商品の情報は引き続き`note/企画/進行キュー.md`と各本文ファイルを参照する。次にこれら3商品で無料note・X集客部の作業を行う場合は、先にこのフォルダへ商品情報ファイルを作成する。
